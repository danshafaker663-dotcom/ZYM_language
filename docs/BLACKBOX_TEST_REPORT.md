# ZYM 黑盒自动测试报告

## 1. 测试目标

黑盒测试不导入 Lexer、Parser 或 Interpreter 的 Python 类，而是把 `.zym` 文件作为用户程序，通过命令行启动一个独立解释器进程。测试只观察公开行为：标准输入、标准输出、标准错误和进程退出码。

## 2. 一键运行

在项目根目录执行：

```powershell
python tests/run_all.py
```

该命令依次运行：

1. 60 项 Python 单元测试和集成测试；
2. 53 个使用 ZYM 编写的黑盒程序；
3. 汇总两个阶段的成功状态和总耗时。

只运行 ZYM 黑盒测试：

```powershell
python tests/run_blackbox.py
```

## 3. 测试文件组织

- `tests/blackbox/cases/`：53 个 `.zym` 测试程序；
- `tests/blackbox/manifest.json`：每个程序的输入、预期输出、预期错误片段和退出码；
- `tests/run_blackbox.py`：子进程测试驱动；
- `tests/results/latest_blackbox.log`：最近一次逐用例原始日志；
- `tests/run_all.py`：一键执行全部测试。

## 5. 最新结果

- 日期：2026-11-15

- ZYM 黑盒测试：53/53 通过
- 黑盒测试耗时：6.501504 秒
- 一键全部测试耗时：7.998117 秒

每个黑盒用例均启动独立 Python 进程，因此总耗时主要包含解释器进程启动成本，不能直接视为 ZYM 程序本身的执行性能。

## 6. 判定规则

正常程序必须同时满足：退出码为 0、stdout 完全相同、stderr 为空。错误程序必须同时满足：退出码与错误类别相符、stdout 与预期相同、stderr 包含指定错误类别和关键原因。任意一项不符即判定该用例失败，并在终端和日志中输出差异。
