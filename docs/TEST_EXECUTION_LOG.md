- 失败现象：Parser 在多个合法语句的结束位置报告 `expected field name after '.'`
- 根因：句点既用于结构字段访问，也用于结束语句；初始实现把所有句点都当成字段访问符。
- 修复：仅在句点后紧跟 `IDENTIFIER` 时构造 `FieldAccess`，其他句点留给语句解析逻辑消费。
- 状态：首次执行失败，问题已定位并修复
